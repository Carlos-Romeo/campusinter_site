### PROMPT PRINCIPAL

---

**RÔLE** : Tu es un développeur web senior spécialisé front-end et intégration Joomla. Tu conçois un site vitrine ultra-dynamique, animé, moderne et « premium » pour **CAMPUS INTER**, une agence de mobilité internationale (études, emploi, visa, installation en Europe) située à Bè-Kpota, Lomé, Togo.

**PLATEFORME** : Le site sera intégré sous **Joomla**. Chaque page correspond à **un article Joomla** dans lequel tu colleras un bloc HTML complet. Ton code doit donc être **autonome** :
- Le CSS propre à la page est embarqué dans une balise `<style>` en tête du bloc (préfixé `.ci-` pour éviter tout conflit avec le template Joomla).
- Le JS propre à la page est embarqué dans une balise `<script>` en fin de bloc, enveloppé dans un IIFE `(function(){ ... })();`, sans dépendance extérieure si possible (sinon, import depuis CDN en `defer`).
- **Chaque ligne de code doit être commentée en français** (rôle de la section, des animations, des étapes Joomla).
- Ajoute en haut de chaque fichier un **en-tête de commentaire** : nom de la page, version, date, notes d'intégration Joomla (article ID, catégorie, menus associés).
- Aucun ID global répété entre les pages ; tout est scopé.
- Fournis pour chaque page le **HTML + CSS + JS** dans un seul fichier, prêt à coller, avec les instructions d'intégration (emplacement dans l'article Joomla, images à déposer dans le Media Manager).

## PARTIE 4 — NOTES D'INTÉGRATION JOOMLA (bonnes pratiques)

1. **Un article par page** : les blocs HTML/CSS/JS se collent dans l'éditeur d'article en mode code (JCE ou CodeMirror natif). Désactiver l'assainisseur HTML si besoin (configuration filtres de texte).
2. **CSS/JS global vs page** : les styles du template (header, footer, boutons, cartes) vont dans le fichier CSS du template (`templates/[template]/css/custom.css`). Le CSS scopé `.ci-` reste dans l'article pour éviter les conflits.
3. **Menus & méga-menu** : créer la hiérarchie de menus (Visa Étude > France/Belgique, etc.), activer l'option « Afficher en méga-menu » si le template le permet.
4. **Formulaires** : utiliser le composant natif Contacts ou RSForm! Pro ; le formulaire « Démarrer mon projet » peut être un module custom HTML stylé `.ci-`.
5. **Médias** : importer les images (logo 2026, photos agence, logos partenaires) dans Gestionnaire de médias ; référencer les chemins relatifs.
6. **SEO** : baliser chaque article (meta description, alias), installer une extension SEF (sh404SEF ou core SEF), plan de site XML, données structurées JSON-LD (LocalBusiness, FAQPage).
7. **Sauvegardes** : Akeeba Backup avant toute intervention + plan de maintenance.
8. **Sécurité** : verrouiller l'admin, activer 2FA, limiter les plugins, HTTPS forcé.
