# Prompts image Campus Inter — classés par page

Utilisez les prompts en anglais pour obtenir un rendu plus fiable dans la plupart des générateurs. Pour chaque image : **photographie authentique, lumière naturelle, grain photo léger, couleurs vert profond / beige / blanc discrètes, diversité africaine réaliste, aucun texte lisible, aucun logo, aucune marque, aucune main ou doigt déformé, pas de rendu 3D ni illustration**.

Ne générez pas les logos Campus Inter ou partenaires : conservez les fichiers officiels existants.
