# Images requises pour le template Campus Inter

## Fichiers à ajouter dans le dossier `images/`

### 1. logo.png (OBLIGATOIRE)
- **Description** : Logo officiel de Campus Inter
- **Dimensions recommandées** : 280 x 80 pixels (format PNG avec transparence)
- **Utilisation** : Affiché dans le header fixe de toutes les pages
- **Note** : Si le fichier n'est pas présent, le navigateur affichera une icône d'image cassée

### 2. hero-bg.jpg (RECOMMANDÉ)
- **Description** : Photo de fond pour la bannière d'accueil
- **Dimensions recommandées** : 1920 x 1080 pixels (format JPG haute qualité)
- **Sujet suggéré** : Campus international, étudiants souriants, vue aérienne de campus européen ou canadien
- **Utilisation** : Arrière-plan animé de la section hero avec effet de zoom progressif

### 3. stats-bg.jpg (OPTIONNEL)
- **Description** : Motif de fond discret pour la section statistiques
- **Dimensions recommandées** : 1920 x 600 pixels
- **Sujet suggéré** : Motif géométrique abstrait ou photo très floutée d'étudiants
- **Utilisation** : Overlay subtil derrière les chiffres clés

## Logos des partenaires

Les logos des groupes partenaires (Galileo GGE, MediaSchool, OMNES, MBN, HEMA) sont actuellement représentés par des placeholders textuels. Pour un rendu professionnel :

- Remplacer les `<div class="logo-placeholder">...</div>` dans `index.php` par des `<img>` avec les vrais logos
- Formats recommandés : PNG ou SVG avec fond transparent
- Dimensions : 200 x 200 pixels maximum

## Où trouver des images libres de droits ?

- https://unsplash.com (Photos haute qualité gratuites)
- https://www.pexels.com (Photos et vidéos libres)
- https://www.flaticon.com (Icônes et logos)

## Optimisation des images

Pour de meilleures performances :
- Compresser les images avec https://tinypng.com ou https://squoosh.app
- Utiliser le format WebP quand possible
- Définir les dimensions exactes dans le code CSS pour éviter le layout shift
